# comments
* A comment is a text that is ignored during execution

* comments can be used to explain a code and make it more readable and easy to understand
* comments can be used to prevent other code execution or code clashing when testing or running an alternative code.

## types of comments

* single-line comment(//) starts with two forward slashes
* any text between the two forward slashes and the end of the line is ignored by the terminal or compiler(which means will not be considered as an executable programme).

* go multi-line comment
it starts with /* and ends with */ and any text between /* and */ will be ignored by the compiler

* the commented code can also be saved for reference or execution
